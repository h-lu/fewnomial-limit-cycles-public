# Nonlinearity initial submission package

Research paper by Haibo Lu, Shanghai Institute of Technology, ORCID 0009-0000-2717-5968. Use the named PDF for single-anonymous review.

- `main.pdf`: complete manuscript, with inline figures and tables, 12-point type and declarations. Scientific text unchanged from [v1.0.1](https://github.com/h-lu/fewnomial-limit-cycles-public/tree/v1.0.1).
- `cover-letter.pdf`: cover letter; the Markdown and LaTeX versions are editable.
- `low-N-supplement.pdf`, `unrestricted-fields.pdf`, `binary-saddle-tree.pdf`: accompanying PDFs. Preserve filenames for the manuscript's companion links.
- `fewnomial-replay.zip`: verification code, inputs and reference outputs. Upload as supplemental research data if appropriate; the complete public archive is at [Zenodo](https://doi.org/10.5281/zenodo.24575586).
- `submission-latex.zip`: updated submission source and companion sources, for use if requested.
- `SHA256SUMS`: checksums for the listed files.

For first submission, upload the files individually as manuscript, cover letter and supplementary files, rather than uploading the outer package as the main file.
